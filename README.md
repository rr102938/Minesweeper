# Minesweeper AI (CS50 AI)

## What it does
* This is an interactive Minesweeper game built with Python and Pygame.
* It features an automated AI agent that uses propositional logic and knowledge bases to make safe moves, deduce mine locations, and play the game automatically.

## Technologies Used
* Python
* Pygame
* Git / GitHub

## How to Run It
Make sure you have Pygame installed on your computer by running this in your terminal:
  * "```bash"
  * pip install pygame
  * Run the main game script: python runner.py
  * Click "Play Game" to start, use the mouse to play manually, or click the "AI        Move" button to let the computer solve the board for you.
